ONE DOWNLOAD FOR EVERYONE (NEW IN 0.7)
--------------------------------------
0.7 replaces every earlier OStim Beast Form download (Merged, the TWO
Edition, the Merged TWO Patch and the TWO Herm Patch). There is one zip with
one installer, and every setup uses the TWO - Total Werewolf Overhaul 4.1
body by Frosferes. TWO is REQUIRED and NOT included:
  https://www.loverslab.com/topic/159911-two-total-werewolf-overhaul/

This mod uses the TWO body made by Frosferes, at the LoversLab community's
request. If Frosferes comes out of retirement and asks for it to be taken

Until then, anyone is free to make their own patches, hubs and mods based on
this one.

THE INSTALLER (read every page; wrong options = the mod won't work)
-------------------------------------------------------------------
1. TWO user or Growl user (pick one)
   - Growl user (ticked by default, recommended for Nolvus users):
     OStim_Beast_Form_Merged.esp + OStim_Beast_Form_Merged_TWO_Patch.esp +
     OStim_Beast_Form_Merged_TWO_Patch - BFA Heads.esp. Same plugins as
     Merged 0.6 + the Merged TWO Patch 0.1.
     Growl: https://www.nexusmods.com/skyrimspecialedition/mods/31245
   - TWO user (no Growl):
     OStim_Beast_Form_TWO.esp + OStim_Beast_Form_TWO - BFA Heads.esp. Same
     plugin as OStim Beast Form - TWO Edition 0.2.
2. Do you use softbody? (pick one)
   - No (ticked by default): nothing softbody-related is installed. In
     scenes, male werewolves get TWO's own hard canine (TWO Core file).
     UNP users, and CBBE / UBE users without softbody, pick No.
   - Yes: installs the GT Softbody werewolf cock meshes and textures; male
     werewolves wear the GT Softbody cock in scenes (the Merged 0.6 look).
     SOFTBODY: https://www.nexusmods.com/skyrimspecialedition/mods/152103
3. Hermaphrodite patch? A.K.A. Fruta? (optional, unticked)
   For TWO Extras' herm / urta PLAYER werewolf. Installs
   OStim_Beast_Form_TWO_Herm_Patch.esp; works with either page-1 choice.
   Needs TWO Extras (WerewolvesExtras.esp), plus WerewolvesExtrasGrowl.esp
   if you use Growl. Leave OStim's "Futas use male role" on.
   I am not going to test this myself. If you use TWO's herm or urta
   werewolf, please test it and report any problems in the support section
   of the OStim Beast Form Merged page on LoversLab.
4. Read and acknowledge: one required box, "I have read and understand".

INSTALL (MO2)
-------------
1. Install the requirements and TWO 4.1. Disable HDT Werewolves.
2. Coming from an earlier OStim Beast Form download? Read UPDATING first.
3. Install this zip and answer the four pages.
4. Left pane: this mod below OStim, OCum, MFA, Growl, GT - Softbody,
   OCreatures Reforged, the animation packs and SkyrimNet/OStimNet. Put TWO
   (then TWO Alternate Textures, then your TWO BodySlide output) below this
   mod. Better Facial Animations and the Pandora output go last.
5. Right pane, by hand (no LOOT):
   Growl option:
     MonsterLipSync1.esp, Growl - Werebeasts of Skyrim.esp (+ patches),
     OCreatures.esp (optional), Werewolves.esp, WerewolvesGrowl.esp,
     OStim_Beast_Form_Merged.esp,
     OStim_Beast_Form_Merged_TWO_Patch.esp            (directly below it)
     OStim_Beast_Form_Merged_TWO_Patch - BFA Heads.esp
     OStim_Beast_Form_TWO_Herm_Patch.esp              (Herm option only)
   TWO option:
     MonsterLipSync1.esp, OCreatures.esp (optional), Werewolves.esp (+ other
     Werewolves*.esp), OStim_Beast_Form_TWO.esp,
     OStim_Beast_Form_TWO - BFA Heads.esp,
     OStim_Beast_Form_TWO_Herm_Patch.esp              (Herm option only)
   NOLVUS: never place a plugin below Paper Maps. Put these as low as you can
   but ABOVE the Paper Maps plugins.
6. Run Pandora.
7. In game, open the "OStim Beast Form" MCM and set the start-scene hotkey.

UPDATING
--------
First: human form, no scene, save, quit the game and MO2, back up. Reinstall
over the old mod with MO2's "Replace".
- Merged 0.6 + Merged TWO Patch 0.1: pick Growl (softbody Yes if you run
  GT - Softbody). Then disable / remove the old TWO Patch mod; 0.7 contains
  its plugin. Same plugin names and FormIDs: your save keeps working. No
  Pandora run needed.
- Plain Merged 0.6: pick Growl. This is a body switch: install TWO 4.1 (Core
  + Growl patch) and MFA, disable HDT Werewolves. The plugin keeps its name
  and FormIDs, so the save keeps working, but werewolves now look like TWO.
- TWO Edition 0.2: pick TWO, remove the old TWO Edition mod. Same plugin.
- TWO Herm Patch 0.1: tick Hermaphrodite, remove the old Herm Patch mod.
- Old standalone Beast Form / Beast Lite / Beast Aware / Werewolf Shot /
  Beast Pie / BFA Heads mods: disable them.
Never enable OStim_Beast_Form_TWO.esp together with
OStim_Beast_Form_Merged.esp. Switching a save between the Growl and TWO
options isn't supported.
